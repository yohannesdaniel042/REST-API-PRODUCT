#  Movie Explorer

## About the Project

Movie Explorer is a simple movie website I built as part of my Codveda Full-Stack Development Internship.

The idea behind this project was to create a website where users can explore popular movies and search for their favorite films. I used the TMDB API to get real movie information and display it dynamically on the webpage.

## Features

- Browse popular movies.
- Search for movies by title.
- View movie posters and titles.
- See movie release dates and ratings.
- Responsive layout for different screen sizes.
- Basic error handling when API requests fail.

## Technologies Used

- **HTML5** – To structure the website.
- **CSS3** – To style the website and make it responsive.
- **JavaScript** – To handle API requests and display movie information dynamically.
- **TMDB API** – To retrieve movie information and posters.

## Getting Started

To run this project on your computer:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Add your own TMDB API key in `script.js`.
4. Open `index.html` using a local development server, such as VS Code Live Server.
5. Start exploring and searching for movies!

## API Information

This project uses [The Movie Database (TMDB) API](https://developer.themoviedb.org/docs) to retrieve movie information.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Project Purpose

This project helped me practice working with external APIs, JavaScript's Fetch API, DOM manipulation, and responsive web design. It also gave me an opportunity to apply what I've been learning in a practical project.
